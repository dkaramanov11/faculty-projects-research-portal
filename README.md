# Faculty Projects Portal

## Overview

Faculty Projects Portal is a web application designed to connect students and professors through academic projects and research opportunities.

The platform allows users to create, manage, and participate in projects while providing a structured workflow for project approval, collaboration, and communication.

---

## Technologies Used

### Frontend

- React.js
- React Router
- CSS

### Backend

- Laravel
- PHP
- REST API

### Database

- MySQL

---

## User Roles

### Student

Students can:

- Browse projects
- Search and filter projects
- Request to join projects
- Receive notifications
- Manage their profile

### Professor

Professors can:

- Create projects
- Manage project participants
- Invite users to projects
- Create project categories
- Receive and respond to requests

### Administrator

Administrators can:

- Approve or reject projects
- Approve or reject professor role requests
- Manage users
- Manage notifications and requests
- Monitor platform activity

## Application Workflow

1. Users register and log into the system.
2. Professors create projects.
3. Administrators review and approve projects.
4. Students browse available projects.
5. Students can request to join projects.
6. Professors can approve or reject requests.
7. Users receive notifications through the Inbox system.
